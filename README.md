# On-Device SystemVerilog / UVM Verification

SystemVerilog와 UVM을 이용한 RTL 기능 검증 프로젝트 및 학습 결과를 정리하는 포트폴리오 저장소입니다.

## Focus Areas

- SystemVerilog Testbench 및 Interface 설계
- Directed Test와 Constrained Random Verification
- Assertion 기반 프로토콜·타이밍 검증
- Code Coverage와 Functional Coverage 분석
- Transaction, Generator, Driver, Monitor, Scoreboard 구조
- UVM Component·Object, Phase, Factory 및 Sequence

프로젝트별 검증 계획, 테스트 시나리오, 커버리지와 결과 분석을 순차적으로 정리합니다.
